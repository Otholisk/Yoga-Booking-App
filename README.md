# Yoga Booking App

This is a web application for a Yoga & Mindfulness Studio booking system.  
It was built using Node.js, Express, Mustache templates and NeDB.

---

## Live Site 

https://yoga-booking-app-98dd3d9d4586.herokuapp.com/

---
## How to Run This Project

1. Install Dependencies:

   Make sure you are in the same directory as the package.json file and run the command 

   npm install
   
2. Start the Server:
  
   node index.js

3. Open in Browser:

   http://localhost:3000

## Features implemented

### Public
- View homepage with available courses
- Browse and filter courses by level
- Search courses by title
- View course details and sessions

### Users
- Login as users
- Book full courses
- Book individual drop-in sessions where available

### Organiser
- Organiser dashboard
- Add, edit and delete courses 
- View class lists with participant names and booking status
- Add organiser accounts
- Remove user accounts
